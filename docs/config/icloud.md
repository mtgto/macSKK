# iCloud

設定画面の「iCloud」タブにある設定項目です。

同じApple Accountでサインインした複数のMacの間で、macSKKの設定を同期できます。同期には[iCloudのキーバリューストア](https://developer.apple.com/documentation/foundation/nsubiquitouskeyvaluestore)を使用します。

## 設定をiCloudで同期する

同期全体のオン・オフを切り替えます。初期値は無効です。

有効にしただけでは何も同期されません。下の「同期する設定」で選んだものだけがiCloudに保存されます。

## 同期する設定

設定画面の区分ごとに、同期するかどうかを選びます。初期値はすべて無効です。

| 分類 | 同期される設定 |
|---|---|
| 一般 | Enterキーの動作、候補選択キー、句読点、入力モードパネル、注釈の表示、▽▼の表示など |
| 変換候補パネル | 変換候補と注釈のフォント・フォントサイズ・背景色 |
| 補完 | 補完候補の表示、ピリオドでの確定、補完までの待ち時間など |
| キーバインド | キーバインドのセットと、選択中のセット |
| 日付変換 | 日付変換の読みと変換フォーマット |
| 直接入力 | 直接入力を有効にしたアプリの一覧 |
| 互換性の設定 | アプリごとのワークアラウンドの設定 |
| SKK辞書サーバー | 接続エラーによる自動無効化の閾値 |

**どの分類を同期するかはMacごとに選べます。** この選択自体は同期されないため、「業務用のMacではキーバインドだけ受け取る」といった使い方ができます。

## 同期されない設定

次の設定は環境に依存するため、意図的に同期していません。

| 設定 | 理由 |
|---|---|
| 辞書の設定 | 辞書ファイルがそのMacにあるかどうかに依存するため |
| ローマ字かな変換ルールの選択 | ルールファイルがそのMacにあるかどうかに依存するため |
| キー配列 | Macごとに異なりうるため |
| SKK辞書サーバーの接続先 | 接続先がMacごとに異なりうるため |
| プライベートモード | 一時的な状態のため |

## iCloudとこのMacで設定が異なる場合

同期を有効にしたときや分類を追加したときに、iCloudとこのMacで値が異なる設定があると確認のダイアログが表示されます。

- **このMacの設定でiCloudを上書きする**
- **iCloudの設定をこのMacに反映する**

値が同じ設定や、iCloudにまだ保存されていない設定については確認しません。前者はどちらを選んでも結果が同じで、後者はこのMacの値がそのまま保存されるためです。

同期を有効にしたあとは、設定を変更するたびに自動で反映されます。

::: tip 反映までの時間について
iCloudへの保存や他のMacへの反映は即座に行われるとは限りません。macOSが適切なタイミングで通信するため、変更が他のMacに現れるまで多少の時間がかかることがあります。
:::

## iCloudから設定を削除

iCloudに保存したmacSKKの設定をすべて削除し、このMacの同期を無効にします。

分類の同期を外しただけでは、iCloudに保存済みの設定は残ります。他のMacがその設定の同期を続けられるようにするためです。iCloudに預けたデータそのものを消したい場合はこのボタンを使用してください。

各Macに保存されている設定は削除されないため、この操作でmacSKKの入力動作が変わることはありません。

::: caution 元に戻せません
削除したデータは復元できません。

また、他のMacで同期を有効にしたままだと、そのMacが設定をiCloudに保存し直します。iCloudにデータを残さないようにするには、すべてのMacで同期を無効にしてください。
:::
