# iCloud

設定画面の「iCloud」タブにある設定項目です。

同じApple AccountでiCloudにサインインした複数のMacの間で、macSKKの設定と[ユーザー辞書](#user-dictionary)を同期できます。設定とユーザー辞書の同期は別々にオン・オフできます。

設定の同期には[iCloudのキーバリューストア](https://developer.apple.com/documentation/foundation/nsubiquitouskeyvaluestore)を使用します。

## 設定をiCloudで同期する

同期全体のオン・オフを切り替えます。初期値は無効です。

有効にしただけでは何も同期されません。下の「同期する設定」で選んだものだけがiCloudに保存されます。

## 同期する設定

設定画面の区分ごとに、同期するかどうかを選びます。初期値はすべて無効です。

| 分類 | 同期される設定 |
|---|---|
| 一般 | Enterキーの動作、候補選択キー、句読点、入力モードパネル、注釈の表示、▽▼の表示など |
| SKK辞書サーバー | 接続エラーによる自動無効化の閾値 |
| 変換候補パネル | 変換候補と注釈のフォント・フォントサイズ・背景色 |
| 日付変換 | 日付変換の読みと変換フォーマット |
| 補完 | 補完候補の表示、ピリオドでの確定、補完までの待ち時間など |
| キーバインド | キーバインドのセットと、選択中のセット |
| 直接入力 | 直接入力を有効にしたアプリの一覧 |
| 互換性の設定 | アプリごとのワークアラウンドの設定 |

**どの分類を同期するかはMacごとに選べます。** この選択自体は同期されないため、「業務用のMacではキーバインドだけ受け取る」といった使い方ができます。

## 同期されない設定

次の設定は環境に依存するため、現在は同期に対応していません。

| 設定 | 理由 |
|---|---|
| 辞書 | 辞書ファイルがそのMacにあるかどうかに依存するため (ユーザー辞書の中身は[ユーザー辞書の同期](#user-dictionary)で同期できます) |
| ローマ字かな変換ルールの選択 | ルールファイルがそのMacにあるかどうかに依存するため |
| キー配列 | Macごとに異なりうるため |
| SKK辞書サーバーの接続先 | 接続先がMacごとに異なりうるため |
| プライベートモード | 一時的な状態のため |

## iCloudとこのMacで設定が異なる場合

同期を有効にしたときや分類を追加したときに、iCloudとこのMacで値が異なる設定があると確認のダイアログが表示されます。

- **このMacの設定でiCloudを上書きする**
- **iCloudの設定をこのMacに反映する**

値が同じ設定や、iCloudにまだ保存されていない設定については確認しません。前者はどちらを選んでも結果が同じで、後者はこのMacの値がそのまま保存されるためです。

同期を有効にしたあとは、設定を変更するたびに自動で反映されます。

::: tip 反映までの時間について
iCloudへの保存や他のMacへの反映は即座に行われるとは限りません。macOSが適切なタイミングで通信するため、変更が他のMacに現れるまで多少の時間がかかることがあります。
:::

## iCloudから設定を削除

iCloudに保存したmacSKKの設定をすべて削除し、このMacの同期を無効にします。

分類の同期を外しただけでは、iCloudに保存済みの設定は残ります。他のMacがその設定の同期を続けられるようにするためです。iCloudに預けたデータそのものを消したい場合はこのボタンを使用してください。

各Macに保存されている設定は削除されないため、この操作でmacSKKの入力動作が変わることはありません。

::: caution 元に戻せません
削除したデータは復元できません。

また、他のMacで同期を有効にしたままだと、そのMacが設定をiCloudに保存し直します。iCloudにデータを残さないようにするには、すべてのMacで同期を無効にしてください。
:::

## ユーザー辞書の同期 {#user-dictionary}

変換・単語登録・削除した結果を、他のMacのユーザー辞書にも反映します。同期には[CloudKit](https://developer.apple.com/documentation/cloudkit)を使用します。

::: info 動作環境
- macOS 14以降が必要です。macOS 13では同期のトグルが無効になります
- iCloudにサインインしている必要があります
:::

### ユーザー辞書をiCloudで同期する

同期のオン・オフを切り替えます。初期値は無効です。

初めて有効にするときは、このMacのユーザー辞書にすでにある単語をどう扱うかを選びます。

| 選択肢 | 動作 |
|---|---|
| **これ以降の変換だけ同期** | 同期を開始してから変換・単語登録・削除した単語だけをiCloudに送ります。すでにある単語も、もう一度変換すれば送られます |
| **すべて同期** | すでにある単語もすべてiCloudに送ります |

どちらを選んでも、iCloudにある他のMacの単語はこのMacに取り込みます。

「すべて同期」を2台目以降のMacで選んだ場合、変換候補の順序は先に同期を開始したMacのものが優先されます。このMacにだけある単語は、iCloudにある単語より後ろに並びます。

同期を無効にしても、iCloud上のデータとこのMacのユーザー辞書は削除されません。もう一度有効にすると、最初の選択からやり直します。

### 同期の状態

同期を有効にしている間は、同期の状態 (取得中・反映中・送信中・最終同期日時) とエラーが表示されます。

同期は次のタイミングで行われます。

- 変換・単語登録・削除をしたとき
- 5分ごと
- 設定の **今すぐ同期** ボタンを押したとき

他のMacでの変更が反映されるまでには、最大で5分ほどかかります。急ぐときは「今すぐ同期」を押してください。

他のMacでの変更を取り込むと、通知センターに追加・更新・削除の件数が表示されます。

### 同期の仕組み

- 変換候補ごとに、最後に変換・単語登録・削除した日時を記録し、新しいほうを採用します。同じ単語をあるMacで削除したあと、別のMacでまだ同期する前に変換した場合は、変換のほうが新しいので削除されずに残ります
- 変換候補の並び順は、最後に変換した日時の新しい順になります
- **注釈は同期しません。** このMacのユーザー辞書にある注釈はそのまま残ります
- iCloudに保存するデータは暗号化されます。iCloudの「高度なデータ保護」を有効にしている場合は、エンドツーエンドで暗号化されます

### 同期が自動で停止する場合

次の場合は同期を自動で停止し、通知センターと設定画面に理由を表示します。もう一度有効にすると、最初の選択からやり直します。

- iCloudからサインアウトした、または別のApple Accountに切り替えた
- 他のMacで[iCloudからユーザー辞書を削除](#remove-user-dictionary)した

### iCloudからユーザー辞書を削除 {#remove-user-dictionary}

iCloudに保存したユーザー辞書をすべて削除し、このMacの同期を無効にします。iCloudに送りたくなかった単語を送ってしまった場合などに使用してください。

ユーザー辞書を同期している他のMacは、削除を検知すると同期を停止します。

::: caution 元に戻せません
削除したデータは復元できません。

各Macのユーザー辞書からは削除されません。単語そのものを消したい場合は、各Macのユーザー辞書からも削除してください。
:::
