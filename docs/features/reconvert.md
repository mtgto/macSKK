# 確定アンドゥと再変換

確定した文字列を、もう一度変換し直すための機能です。macSKKには「確定アンドゥ」と「選択テキストを再変換」の2つがあります。

| | 確定アンドゥ | 選択テキストを再変換 |
|---|---|---|
| デフォルトキー | ⌃⇧R | ⌃/ |
| 対象 | 直前に変換して確定した文字列 | 選択中のテキスト |
| テキストの選択 | 不要 | 必要 |
| 戻る状態 | 変換候補選択 (▼) | 読み入力 (▽) |
| 読みの求め方 | 確定したときの読みをそのまま使う | 辞書から逆引きする |

どちらもキーは[キーバインド](../config/keybinding)の設定で変更できます。

## 確定アンドゥ

直前に確定した文字列を、確定する前の変換候補選択 (▼) の状態に戻します。[ddskk](https://github.com/skk-dev/ddskk) の確定アンドゥ (`skk-undo-kakutei`) と同じ機能です。

たとえば「きしゃ」を変換して「記者」で確定してしまったときに、⌃⇧R を押すと「▼記者」に戻ります。そのままスペースを押せば次の変換候補 (「汽車」など) を選べます。

- 確定したときに選んでいた変換候補が選択された状態で戻ります。辞書は引き直さないので、確定によって変換候補の順番が変わっていても、確定する前と同じ並びで表示されます
- 前候補キー (`x`) を続けて押せば読み入力 (▽) まで戻れます
- 読み入力 (▽) まで戻ってからキャンセルすると、元の確定文字列に戻ります
- 確定したあとに続きを入力していても、確定した文字列がそのまま残っていれば戻せます

### 使える条件

- ひらがな・カタカナ・半角カナモードで、未確定の入力がないときに使えます
- 対象は直前に変換して確定した1回だけです。さらに前の確定には戻れません
- 確定した文字列を書き換えたり削除したりした場合は戻せません。確定した位置より前を編集した場合も戻せないことがあります
- 変換候補を選ばずに確定した文字列 (ひらがなのまま確定したものなど) や、バックスペースで末尾を削って確定した文字列は対象外です
- 単語登録中に確定した文字列は対象外です

確定アンドゥできないときにキーを押しても何も起きません (キーはアプリに渡されません)。

### 対応していないアプリ

確定アンドゥは、アプリ上の確定済みの文字列を未確定文字列に置き換えることで実現しています。この置き換えに対応していないアプリでは使えません。

| 対応状況 | アプリ |
|---|---|
| 使える | テキストエディット, Safari, Chrome, Slack, Obsidian など |
| 確定した直後だけ使える (続きを入力したあとは戻せない) | ターミナル (Terminal.app) |
| 使えない | iTerm2, WezTerm, Ghostty, Hyper |

iTerm2とHyperは、確定アンドゥしてもアプリ側で正しく扱えないため、macSKK側で確定アンドゥを無効にしています (キーを押しても何も起きません)。iTerm2は確定した文字列を未確定文字列に置き換えられず、Hyperは変換候補の表示まではできるものの、候補を選んで確定しても何も入力されません。WezTermとGhosttyは確定した文字列を見つけられないため、確定アンドゥできません。

::: tip
上の表にないアプリで確定アンドゥがおかしな動きをする場合は [Issue](https://github.com/mtgto/macSKK/issues) でお知らせください。
:::

### 確定し直したあとのカーソル位置

確定アンドゥから確定し直したときや、キャンセルで元の文字列に戻したときのカーソルは、その語の直後に来ます。続きを入力したあとに確定アンドゥした場合も、元のカーソル位置 (続きの末尾) には戻りません。

1. 「かくてい」を「各停」と確定し、続けて「する」と入力して `各停する|` になる (`|` はカーソル)
2. ⌃⇧R を押すと「各停」が `▼各停` に戻り、`▼各停する` になる
3. スペースで「確定」を選んで確定すると `確定|する` になる

ddskkのデフォルトと同じ動作です。

## 選択テキストを再変換

選択中のテキストを辞書から逆引きして、その読みの読み入力 (▽) の状態にします。

たとえば文書中の「汽車」を選択して ⌃/ を押すと「▽きしゃ」になり、スペースで変換し直せます。

- 確定アンドゥと違い、直前に確定した文字列でなくても、選択できるテキストであれば何でも対象にできます
- 読み入力 (▽) の状態からキャンセルすると、元のテキストに戻ります
- 辞書に見つからないテキストでは何も起きません
- 送り仮名つきの単語 (「言う」など) の逆引きには対応していません
- 同じ単語が複数の読みで辞書に登録されている場合、どの読みになるかは選べません
